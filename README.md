# Edmunds Event Centre

Create a premium, responsive single-page website for "Edmunds Event Centre" in Wuse 2, Abuja, Nigeria.

Design & Theme:
- Aesthetics: High-end luxury hospitality feel using deep navy/slate, warm gold/champagne accents, crisp white cards, and subtle borders.
- Typography: Classic display serif heading font paired with a clean, modern sans-serif body.
- Assets: Use Lucide icons and lightweight Unsplash placeholder images of luxury marquees, banquet halls, and wedding receptions (do NOT embed base64 images into the code).

   - CTAs: "Book an Inspection" (opens modal) and a direct call button with phone icon.

2. Hero Section:
   - Headline: "Abuja’s Premier Grand Event Venue"
   - Subtitle: "Experience unmatched space, luxury ambience, and world-class hospitality in the heart of Wuse 2 for grand weddings, banquets, and corporate conferences."
   - Badges: "2,000 Capacity Marquee", "Full Climate Control", "Dedicated VIP Parking".
   - CTAs: "Inquire About Dates" and "Explore Venue".

3. Key Metrics Ribbon:

4. Venue Amenities & Features:
   - Grand Marquee: Soaring ceilings, expansive pillar-free floor space adaptable for banquet or theatre layouts.
   - Climate Control: High-capacity commercial 5HP standing ACs throughout.
   - VIP & Executive Suites: Private luxury dressing rooms and holding lounges for bridal parties and VIPs.

   - Fields: Full Name, Phone Number, Event Type (Wedding Reception, Conference, Gala, Birthday), Expected Guests, Preferred Date.

7. Contact, Location & Footer:
   - Address and direct Google Maps embed/card.
